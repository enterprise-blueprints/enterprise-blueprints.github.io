# Working notes

A shared space for thinking through the direction of Enterprise Blueprints:
design proposals, open questions, and decisions in progress.

Nothing in this folder is published on the site. Jekyll is configured to skip
it, and the content validator doesn't read it. Notes can be rough. When an idea
settles, move what matters into the site content, the registries in `_data/`,
or the main README.

## Notes

- [Building block metamodel v0.2](building-block-metamodel-v0.2.md) — how the
  building block types relate, intrinsic and contextual relationships, and the
  case for treating patterns and governance differently from core elements.
- [Enterprise Blueprints v0.2](enterprise-blueprints-v0.2.md) — the v0.2
  handoff: light capability contracts, traceable mission outcomes, direct and
  indirect reuse, and the Grants additions. What was decided is in the main
  README's "Modeling decisions" section.
- [Solution Studio alignment](solution-studio-alignment.md) — how Solution
  Studio reads the library, what the v0.2 rebuild changed for it, and what
  each project needs to line up again.
