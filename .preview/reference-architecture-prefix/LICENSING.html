Licensing and attribution

Enterprise Blueprints follows the licensing split established in Charter v0.5.

Material Applicable license
Written architecture, charter, repository guides, Markdown templates, diagrams, and educational prose Creative Commons Attribution 4.0 International
Software, example code, reference implementation code, machine-readable schemas, and similar software artifacts MIT License

The split applies by material, not just directory or file extension. YAML metadata accompanying a Markdown document is part of that document. Software examples embedded in documentation use MIT; the surrounding explanatory prose uses CC BY 4.0. Implementation and lab documentation remains CC BY 4.0.

New mixed-material artifacts should state the applicable licenses where the boundary is not clear. Retain third-party license and attribution notices; third-party material is not relicensed by this statement.

The bundled Inter fonts retain their SIL Open Font License 1.1. The brand boards in brand_kit/ serve as supplied design references and do not receive a new license through this statement.

Attribution

Credit Enterprise Blueprints and any creators identified in the artifact. When sharing documentation or diagrams, include a link to the source artifact, the CC BY 4.0 license, and an indication of changes. Preserve supplied attribution and notices. Software reuse must retain the MIT copyright and permission notice.

Example documentation attribution:

Adapted from “[artifact title]” by Enterprise Blueprints, [source artifact URL], licensed under CC BY 4.0. Changes: [brief description].

The full license texts control. Official sources: CC BY 4.0 legal code and MIT License.
