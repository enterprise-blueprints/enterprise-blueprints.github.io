Sections of a building block

Building block pages share their opening and closing sections. In between, each type has sections of its own, because each type answers different questions. Entities describe data only, so they leave out the shared sections about how a block is used. Sections in bold appear on every written block; the rest are added where they help. Relationships and Mission Blueprint usage are added to every page automatically.

Relationship types

Each relationship reads one way from the first block and the other way from the second. For example, Case Management manages Case, and Case is managed by Case Management.
