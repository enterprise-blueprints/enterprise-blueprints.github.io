Building blocks describe what the enterprise needs in vendor-neutral terms. An Implementation Guide describes how a particular technology or product can realize one or more of those blocks. Guides point at the blocks they realize. Blocks never depend on a guide, so a logical definition stays the same no matter how many ways it's implemented.
