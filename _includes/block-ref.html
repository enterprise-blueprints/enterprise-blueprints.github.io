{%- comment -%} Resolves a building block ID to its canonical page and renders a link. Jekyll reserves `id` on documents, so the lookup uses the filename slug. The validator guarantees every block's filename equals its `id`. An ID that does not resolve renders a visible warning instead of vanishing.
