# Diagrams

Store diagrams that explain architecture artifacts here.

The [enterprise capability map](enterprise-capability-map.html) is an editable HTML diagram embedded in [The Enterprise Capability Map](../../foundations/enterprise-capability-map.md). It expands the reference architecture's Enterprise Capabilities layer into business and shared capability groups, connects them to Enterprise Entities and State, and uses the same cross-cutting controls and technology realization view. Its text and links render without JavaScript. The site stylesheet supplies its layout, including a stacked layout for narrow screens.

The [AI-native enterprise stack](ai-native-enterprise-stack.html) is an editable HTML diagram embedded in the [AI-Native Enterprise Reference Architecture](../../reference-architecture/ai-native-enterprise.md). It stacks Experiences, Enterprise Capabilities, Orchestration, and Enterprise Entities and State, places controls alongside them, and separates technology realizations. Links lead to each responsibility's explanation. Controls move below the layers on narrow screens.

Both views share a blueprint canvas, numbered layer badges, compact example chips, and continuous control rails. The capability view reuses layer numbers 02 and 04 to show its place in the reference model. Text links show an underline on hover or keyboard focus. The site stylesheet adapts the layout to the diagram's available width and supplies print styles. Outline icons come from the site's existing SVG sprite.

Use lowercase kebab-case filenames, link each diagram from its owning artifact, and keep editable source alongside exported images where practical. Include a textual explanation in the artifact so the architectural meaning is accessible without the image.
