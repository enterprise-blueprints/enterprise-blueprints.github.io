# Small-release roadmap (preview only)

This roadmap is not a commitment to build later releases in Release 1. Each milestone is a separately approved increment; timeboxes can change.

| Release | Independent incremental outcome | Constraints |
| --- | --- | --- |
| **R1 (active)** | Publish a generic U.S. federal OIG mission, five capabilities, and one candidate vendor-neutral architecture pattern as readable static pages + validated JSON. | Site only, no agency/customer example. |
| **R2** | Deep-dive into *Audit, Inspection & Evaluation* and publish one companion educational video linked as content metadata. | One capability; no media production platform. |
| **R3** | First local **Solution Studio** workspace with an engagement goal, notes, model elements and relationships. | Manual entry; no AI or customer-specific seed data shipped publicly. |
| **R4** | Preview/import a public OIG Blueprint into Studio, retaining provenance and proposal status. | No auto-acceptance. |
| **R5** | One optional OIG assessment or simple guided checklist with goal-based suggestions. | Rule-based first; no autonomous agent. |
| **R6** | Manually compare two vendor-neutral candidate implementation patterns in separate scenarios. | No product-fit rankings or license cost calculations. |
| **R7** | Generate a versioned, editable draft architecture summary from reviewed model content. | SOW automation deferred until scope and approval are robust. |

Only begin the next increment after reviewing the last result with a human editor/architect. Prefer one useful feature and one meaningful content increment per cycle.
