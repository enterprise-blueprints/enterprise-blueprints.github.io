# Diagrams

Store diagrams that explain architecture artifacts here.

The [enterprise capability map](enterprise-capability-map.html) is an editable HTML diagram embedded in [The Enterprise Capability Map](../../foundations/enterprise-capability-map.md). Its text and links render without JavaScript. The site stylesheet supplies its layout, including a stacked layout for narrow screens.

Use lowercase kebab-case filenames, link each diagram from its owning artifact, and keep editable source alongside exported images where practical. Include a textual explanation in the artifact so the architectural meaning is accessible without the image.

Diagrams use [CC BY 4.0](../../LICENSING.md). Return to the [repository overview](../../README.md).
